LIVE PLAYGROUND / 在线实验区

下面是完整互动作品。可直接拖动圆环、调整时间、切换配色与自动循环速度。

ADJUSTABLE PARAMETERS / 可调参数

TIME / 时间

00:00–23:59。拖动轨道或使用时间滑块，观察场景光照变化。

AUTO CYCLE / 自动循环

12–180 秒 / 天。数值越小，虚拟的一天流逝越快。

COLOR MOOD / 色彩氛围

原始田园、海岸薄雾、薰衣草暮色、琥珀暖光。

LANGUAGE / 界面语言

简体中文、English、日本語。

CLOCK / 时间格式

12 小时制或 24 小时制，也可同步设备本地时间。

PREFERENCES / 偏好设置

速度、主题、语言与时间格式保存在当前浏览器；重置按钮可恢复默认值。

THEME TOKENS / 主题色参数

在 .pixel-orbit 上覆盖以下五个 CSS 变量，即可制作自己的主题：

.pixel-orbit {
  --orbit-bg: #f5ecd9;
  --orbit-surface: #8c9a62;
  --orbit-fg: #1b2146;
  --orbit-muted: #7f97b3;
  --orbit-accent: #efa02c;
}

运行时修改变量后，调用挂载实例的 refreshColors() 刷新画面配色。

DEVELOPER API / 开发接口

const orbit = window.PixelOrbit.mount(
  document.querySelector('.pixel-orbit')
);

orbit.setHour(18);       // 设置为 18:00
orbit.setAutoplay(48);   // 48 秒走完一天
orbit.toggle();          // 切换昼夜
orbit.getHour();         // 读取当前小时
orbit.isNight();         // 是否为夜晚
orbit.refreshColors();   // 刷新配色
orbit.destroy();         // 卸载实例
