开发者参考 · 主题变量与公开 API

覆盖组件的 CSS 自定义属性即可制作配色方案；运行时修改后调用 refreshColors() 更新画面。

背景表面前景雾蓝强调
.pixel-orbit {
  --orbit-bg: #f5ecd9;
  --orbit-surface: #8c9a62;
  --orbit-fg: #1b2146;
  --orbit-muted: #7f97b3;
  --orbit-accent: #efa02c;
}
const orbit = window.PixelOrbit.mount(document.querySelector('.pixel-orbit'));
orbit.setHour(18);
orbit.setAutoplay(48);
orbit.toggle();
orbit.getHour();
orbit.isNight();
orbit.refreshColors();
orbit.destroy();
